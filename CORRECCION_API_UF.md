# Corrección de consulta UF

Se cambió el proveedor principal a `GET https://indicadores.cl/api/v1/uf.json`.
Respaldo: `https://mindicador.cl/api` y `https://mindicador.cl/api/uf`.

La interfaz informa valor, fecha, fuente y equivalente en CLP. No realiza pagos.
La API requiere internet. Si continúa fallando en el emulador, revisar acceso HTTPS desde su navegador y Logcat.

Ver documentación: https://indicadores.cl/api/
